# Команда та відповідальність

## 1. Склад команди

| Учасниця           | Основна роль                                |
| ------------------ | ------------------------------------------- |
| Лопушанська Каріна | розробниця серверної частини, координаторка |
| Климкович Сандра   | розробниця клієнтської частини, аналітикиня |

## 2. Принципи розподілу відповідальності

1. Для кожного напряму визначено **відповідальну** учасницю, яка організовує роботу в ньому та відповідає за результат.
2. Друга учасниця **бере участь** у напрямі: обговорює рішення, переглядає зміни та перевіряє результат.
3. Кожна учасниця виконує завдання як у серверній, так і в клієнтській частині, щоб розуміти загальну структуру системи.
4. Індивідуальний внесок підтверджується призначеними завданнями в переліку завдань, комітами, запитами на включення змін і переглядами коду.

Презентацію та демонстраційні дані учасниці готують спільно.

## 5. Критерії завершеності завдання

Завдання вважається виконаним, якщо:

1. результат відповідає опису завдання та пов'язаним критеріям приймання;
2. код збирається без помилок;
3. для бізнес-логіки додано або оновлено модульні тести;
4. зміни переглянуто та схвалено другою учасницею;
5. за потреби оновлено документацію;
6. запит на включення змін об'єднано з `main`, а завдання переведено в стан "Виконано".
